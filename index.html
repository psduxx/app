FAQ

Common questions

Where is our data stored?

Wherever suits you. We can deploy to Australian cloud regions (such as AWS Sydney or Azure Australia East), to your own cloud account, or on-premises. We handle personal information in line with the Australian Privacy Principles.

Who owns the software?

For custom projects, you own the code and IP once paid. For ready-made products you can subscribe, license, or purchase the source code outright.

We're not sure AI is right for us. Can you help?

Yes. The first consult is free, and we'll tell you honestly if a simpler, non-AI solution would serve you better.

Do you only work remotely?

We work remotely Australia-wide by default, with on-site visits available by arrangement.

How do payments work?

All prices are in AUD and include GST. Projects are invoiced by milestone; support plans and subscriptions are billed monthly.
